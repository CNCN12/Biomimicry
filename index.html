NHIỆM VỤ THỰC HÀNH

Chủ đề: THIẾT KẾ TRANG WEB "GÓC HỌC TẬP CỦA EM"

Em hãy thực hiện theo hướng dẫn bên dưới để tạo một trang web giới thiệu góc học tập cá nhân.

Bước 1. Tạo thư mục và file

  1. Mở Visual Studio Code.
  2. Tạo thư mục có tên OnTapHTML.
  3. Tạo hai file trong thư mục:
  1. index.html: Viết nội dung HTML.
  2. style.css: Viết mã CSS trang trí trang web.
Lưu ý: Hai file phải nằm trong cùng một thư mục để liên kết CSS hoạt động.

Bước 2. Viết mã HTML

Mở fileindex.html, nhập đoạn mã sau: 

<!DOCTYPE html>
<html lang="vi">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

<body>

Giải thích kiến thức cần nhớ:
Thẻ HTMLChức năng
h1,h2 tạo tiêu đề
p Tạo đoạn văn
ul,li Danh sách không thứ tự
ol,liDanh sách có thứ tự
table, tr, th, tdTạo bảng
imgChèn hình ảnh, alt mô tả ảnh
iframeNhúng video YouTube
audio controlsTạo trình phát âm thanh
aTạo liên kết
form, input, textareaTạo biểu mẫu
buttonTạo nút bấm
Chú ý:
  1. target="_blank" giúp liên kết mở ở tab mới.
  2. Địa chỉ video YouTube nhúng phải có dạng /embed/VIDEO_ID.
  3. Font Awesome dùng để hiển thị các biểu tượng ngôi sao và phong bì.
  4. Các thành phần tải từ Internet cần có kết nối mạng.
  5. Nút Gửi chỉ minh họa biểu mẫu, chưa gửi dữ liệu đến máy chủ.

Bước 3. Viết mã CSS

Mở file style.css và nhập đoạn mã: 

/* Định dạng toàn trang */
body {
    background-color: #eef2ff;
    color: #333333;
    margin: 20px;
    font-family: Arial;
}

/* Định dạng khung nội dung */
.khung {
    background-color: white;
    width: 800px;
    padding: 20px;
    margin: 0 auto;
    border: 2px solid #cccccc;
    border-radius: 12px;
}

/* Định dạng tiêu đề */
h2 {
    color: blue;
}

.noibat {
    color: red;
}

#tieude {
    color: darkblue;
    text-align: center;
    font-weight: bold;
}

/* Định dạng bảng */
table, th, td {
    border: 1px solid black;
    border-collapse: collapse;
    padding: 8px;
}

/* Định dạng hình ảnh */
img {
    width: 480px;
    height: 240px;
    border-radius: 10px;
}

/* Định dạng liên kết */
a {
    color: green;
    text-decoration: none;
}

/* Định dạng biểu mẫu */
input, textarea {
    padding: 8px;
    margin: 5px;
}

button {
    padding: 8px;
    margin: 5px;
}
Giải thích kiến thức CSS:
  1. body, h2, img: Selector theo tên thẻ.
  2. .khung, .noibat: Selector theo class.
  3. #tieude: Selector theo id.
  4. color: Màu chữ.
  5. background-color: Màu nền.
  6. border: Đường viền.
  7. border-radius: Bo tròn góc.
  8. padding: Khoảng cách bên trong.
  9. width, height: Chiều rộng và chiều cao.
  10. font-weight: Độ đậm chữ.
  11. text-align: Căn chỉnh chữ.
  12. text-decoration: Trang trí văn bản hoặc liên kết.
Kiến thức quan trọng về độ ưu tiên CSS:

Trong bài thực hành, tiêu đề có đồng thời:

<h1 id="tieude" class="noibat"></h1>

CSS quy định:


.noibat {
    color: red;
}

#tieude {
    color: darkblue;
}

Kết quả: Tiêu đề có màu xanh đậm, không phải màu đỏ.

Vì sao? Vì selector theo id có độ ưu tiên cao hơn selector theo class.

Bước 4. Chạy và kiểm tra sản phẩm

  1. Nhấn Ctrl + S để lưu cả hai file.
  2. Mở file index.html bằng trình duyệt Chrome hoặc Edge.
  3. Quan sát trang web vừa tạo.
  4. Kiểm tra hình ảnh, bảng, danh sách, video, âm thanh, biểu mẫu và màu sắc.
  5. Nếu trang web chưa có màu nền hoặc khung trắng, hãy kiểm tra dòng liên kết style.css và tên file CSS.

Bước 5. Tự thực hành chỉnh sửa

Sau khi trang web hoạt động, em phải tự thực hiện 4 yêu cầu:

  1. Thay nội dung giới thiệu bằng thông tin học tập của bản thân.
  2. Thay đổi ít nhất 2 môn học yêu thích hoặc hoạt động học tập.
  3. Thêm ít nhất 1 hàng mới vào bảng thời gian biểu.
  4. Đổi màu nền trang web và màu tiêu đề bằng CSS.

Yêu cầu: Tự thực hiện các chỉnh sửa, lưu file và tải lại trang web để quan sát sự thay đổi.

CHECKLIST TỰ ĐÁNH GIÁ

Trước khi nộp bài, kiểm tra:

  1. Có cấu trúc HTML chuẩn và tiêu đề trang.
  2. Có tiêu đề, đoạn văn.
  3. Có danh sách ul và ol.
  4. Có bảng với thẻ th
  5. Có hình ảnh và thuộc tính alt.
  6. Có video YouTube bằng iframe.
  7. Có thẻ audio controls.
  8. Có liên kết ngoài mở tab mới.
  9. Có form liên hệ đầy đủ.
  10. Sử dụng file CSS riêng.
  11. Có selector theo tag, class và id.
  12. Hiểu độ ưu tiên của li so với class.
  13. Có các thuộc tính CSS cơ bản.
  14. Liên kết CSS thành công.
  15. Có ít nhất 2 biểu tượng Font Awesome.

SẢN PHẨM NỘP TRÊN CANVAS

Sau khi hoàn thành thực hành:

  1. Chụp màn hình trang web đã chạy trên trình duyệt, thể hiện rõ các phần nội dung. Có thể chụp nhiều ảnh nếu trang web dài.
  2. Chụp màn hình hai file index.html và style.css đang mở trong Visual Studio Code để minh chứng đã thực hiện mã nguồn.
  3. Tải các ảnh chụp lên Assignment trên Canvas và nhấn Submit Assignment.

Không cần nộp file HTML, CSS hay file ZIP. Chỉ cần nộp ảnh chụp màn hình.

HOÀN THÀNH HOẠT ĐỘNG

Em đã hoàn thành khi trang web hiển thị đúng, thực hiện đủ 4 yêu cầu chỉnh sửa ở Bước 5 và nộp ảnh chụp màn hình trên Canvas.
